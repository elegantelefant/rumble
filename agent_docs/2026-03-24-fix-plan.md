### Migrate to Tauri Mock IPC (`@tauri-apps/api/mocks`)

The existing Vitest tests mock `invoke` manually via `vi.fn()`. Tauri provides official mocking via `@tauri-apps/api/mocks` (docs: https://tauri.app/develop/tests/mocking/) which is more robust and handles the IPC protocol correctly.

**Key APIs from `@tauri-apps/api/mocks`:**
- `mockIPC(handler, options?)` — intercept invoke calls, handler receives `(cmd, args)` and returns the simulated result
- `mockWindows('main', 'second', ...)` — fake window labels; first arg is "current" window
- `clearMocks()` — reset all mock state (MUST call in `afterEach`)

**Setup requirement** — jsdom lacks WebCrypto, needs polyfill:
```typescript
beforeAll(() => {
  Object.defineProperty(window, 'crypto', {
    value: { getRandomValues: (buffer) => randomFillSync(buffer) },
  });
});
```

**Sidecar/shell command mocking** — for `spawn()`/`execute()` operations:
```typescript
mockIPC(async (cmd, args) => {
  if (args.message.cmd === 'execute') {
    const eventCallbackId = `_${args.message.onEventFn}`;
    const eventEmitter = window[eventCallbackId];
    eventEmitter({ event: 'Stdout', payload: 'data from process' });
    eventEmitter({ event: 'Terminated', payload: { code: 0, signal: 'kill' } });
  }
});
```

**Event system mocking** (v2.7.0+):
```typescript
mockIPC(() => {}, { shouldMockEvents: true });
const handler = vi.fn();
listen('test-event', handler);
emit('test-event', { foo: 'bar' });
expect(handler).toHaveBeenCalledWith({ event: 'test-event', payload: { foo: 'bar' } });
```
Note: `emitTo` and `emit_filter` are NOT supported yet.

**Changes to existing tests:**
1. In `tests/api-client.test.ts`: replace manual `vi.mock` of `@tauri-apps/api/core` with `mockIPC` from `@tauri-apps/api/mocks`

### Add Selenium E2E Testing via `tauri-driver` (Linux/Windows CI only)

Tauri supports WebDriver-based e2e via `tauri-driver` (docs: https://tauri.app/develop/tests/webdriver/). This is the official way to test the full app (Rust + sidecar + frontend together).

**Platform support:** Linux and Windows only. macOS is NOT supported — WKWebView has no native WebDriver tool.

**How it works:** `tauri-driver` is a cross-platform wrapper that sits between Selenium and the platform's native WebDriver server (WebKitWebDriver on Linux, Microsoft Edge Driver on Windows). It listens on port 4444.

**Setup:**
```bash
cargo install tauri-driver --locked
# Linux also needs:
sudo apt install webkit2gtk-driver xvfb
# Windows also needs:
cargo install --git https://github.com/chippers/msedgedriver-tool
```

**Project structure** — create `selenium-tests/` directory:
```
selenium-tests/
├── package.json
└── test/
    └── test.js
```

**`selenium-tests/package.json`:**
```json
{
  "name": "rumble-selenium-tests",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "scripts": { "test": "mocha" },
  "dependencies": {
    "chai": "^5.2.1",
    "mocha": "^11.7.1",
    "selenium-webdriver": "^4.34.0"
  }
}
```

**`selenium-tests/test/test.js`** — key structure:
- `before()` hook: builds debug app via `pnpm tauri build --debug --no-bundle`, then spawns `tauri-driver` on port 4444
- Driver setup: `new Builder().usingServer('http://127.0.0.1:4444/').withCapabilities({ 'tauri:options': { application: binaryPath }, browserName: 'wry' })`
- `after()` hook: quits WebDriver, kills `tauri-driver`
- Linux uses `xvfb-run` wrapper for headless display

**Smoke test scope** (don't duplicate Playwright coverage):
- App window opens and renders content
- Sidebar is visible with all nav items
- Can navigate between routes via element clicks
- Sidecar health endpoint responds (verifies full Rust→Python pipeline)

**CI workflow** — create `.github/workflows/webdriver.yml`:
```yaml
name: WebDriver E2E

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  selenium:
    name: Selenium (${{ matrix.platform }})
    runs-on: ${{ matrix.platform }}
    strategy:
      fail-fast: false
      matrix:
        platform: [ubuntu-22.04, windows-latest]
    steps:
      - uses: actions/checkout@v4
      - name: Linux deps
        if: matrix.platform == 'ubuntu-22.04'
        run: |
          sudo apt-get update && sudo apt-get install -y \
            libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev \
            patchelf libxdo-dev libssl-dev webkit2gtk-driver xvfb
      - name: Windows Edge Driver
        if: matrix.platform == 'windows-latest'
        run: |
          cargo install --git https://github.com/chippers/msedgedriver-tool
          & "$HOME/.cargo/bin/msedgedriver-tool.exe"
          $PWD.Path >> $env:GITHUB_PATH
      - uses: dtolnay/rust-toolchain@stable
      - uses: Swatinem/rust-cache@v2
        with: { workspaces: src-tauri }
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - uses: pnpm/action-setup@v4
        with: { version: 9 }
      - uses: actions/setup-python@v5
        with: { python-version: "3.12" }
      - uses: astral-sh/setup-uv@v4
      - run: pnpm install
      - run: uv sync
        working-directory: src-tauri/sidecar
      - name: Build sidecar
        if: runner.os != 'Windows'
        run: |
          uv run pyinstaller sidecar.spec --noconfirm
          TRIPLE=$(rustc -vV | grep host | cut -d' ' -f2)
          cp dist/rumble-sidecar ../binaries/rumble-sidecar-$TRIPLE
        working-directory: src-tauri/sidecar
      - name: Build sidecar (Windows)
        if: runner.os == 'Windows'
        run: |
          uv run pyinstaller sidecar.spec --noconfirm
          copy dist\rumble-sidecar.exe ..\binaries\rumble-sidecar-x86_64-pc-windows-msvc.exe
        working-directory: src-tauri/sidecar
        shell: cmd
      - run: cargo install tauri-driver --locked
      - run: npm install
        working-directory: selenium-tests
      - name: Selenium (Linux)
        if: matrix.platform == 'ubuntu-22.04'
        run: xvfb-run npm test
        working-directory: selenium-tests
      - name: Selenium (Windows)
        if: matrix.platform == 'windows-latest'
        run: npm test
        working-directory: selenium-tests
```

**Run only on `main` and PRs** — this builds the full Tauri app + real sidecar binary, so it's heavy (~10 min). Don't run on every push to every branch.
